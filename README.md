# Neatly Uninstaller

Neatly Uninstaller is a minimal Windows application to uninstall programs and clean leftover files.

> [!IMPORTANT]
> This project is in early development and currently not usable

## Planned Features

- Minimal and Clean UI
- List installed Windows applications
- Uninstall installed Windows applications
- Scan for leftover files and folders
- Scan for leftover registry keys
-  Support for Microsoft Store apps
- Support for uninstalling Steam games

## Requirements

- Windows 10 or newer
- [.NET 10](https://dotnet.microsoft.com/download/dotnet/10.0)
